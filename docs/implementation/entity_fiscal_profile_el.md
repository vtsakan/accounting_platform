# Φορολογικό προφίλ και οικονομική καρτέλα — CR007

## Διόρθωση αρχικής επαλήθευσης

Η αρχική εικόνα δημιουργήθηκε, αλλά ο έλεγχος σταμάτησε με3 αποτυχίες
λεζαντών και1 σφάλμα εισαγωγής. Οι55 νέες μέθοδοι δεν φορτώθηκαν και δεν
υπάρχει πλήρες Verified. Η διόρθωση χρησιμοποιεί την υπάρχουσα
allocate_cash, ελληνικές λεζάντες εξαγωγής και σωστή επιλογή «Ανά ετικέτα».
Κρατά ίδιες όλες τις μεθόδους/απαιτήσεις δοκιμών και τις34 migrations.

Το διορθωμένο πακέτο αναγνωρίζει την ακριβή αρχική CR007 ή την αρχική
CR006. Εφαρμόζει μόνο το αντίστοιχο Git patch, διατηρώντας τις πραγματικές
αναφορές και οποιαδήποτε υπάρχουσα δέσμευση CR007 χωρίς επανεγγραφή.
Η επανάληψη του τοπικού ελέγχου εξακολουθεί να απαιτεί1140/1140, όλες
τις36 οικονομικές περιπτώσεις και τον πραγματικό worker/Redis/scheduler.
Το VM και το GitHub παραμένουν στην CR005 σε ρητή αναμονή.

Η **Επεξεργασία** της καρτέλας ανοίγει τέσσερις ενότητες. Τα υπόλοιπα
πελάτη και προμηθευτή εμφανίζονται επάνω με σύνδεσμο στην αναλυτική καρτέλα.
Εμφανίζονται οι χρεώσεις, οι εξοφλήσεις, τα ανεξόφλητα και τα αδιάθετα
ποσά. Θετικό καθαρό υπόλοιπο είναι οφειλή, αρνητικό πίστωση/προκαταβολή.

Στα **Βασικά στοιχεία** επιλέγετε υποχρεωτικά κατάσταση και κατηγορία
προσώπου, και συμπληρώνετε ΑΜΚΑ όπου υπάρχει. Παλιά γενική «Επιχείρηση»
απαιτεί επιλογή της συγκεκριμένης κατηγορίας κατά την επόμενη επεξεργασία.
Η ένδειξη Ανενεργός είναι διαφορετική από την αρχειοθέτηση: αφαιρεί την
επαφή από τις προεπιλεγμένες αναζητήσεις/εκτυπώσεις, κρατώντας την καρτέλα,
τις συμφωνίες, τις εργασίες και τις οφειλές. Η αρχειοθέτηση συνεχίζει να
μπλοκάρεται από ανοιχτές συμφωνίες ή εργασίες.

Στη **Σύζυγο** ενεργοποιείτε την ενότητα και συμπληρώνετε ξεχωριστή ταυτότητα.
Η επιλογή κοινών στοιχείων ενημερώνει αυτόματα την επικοινωνία από τον
υπόχρεο. Αν την αποεπιλέξετε, κρατάτε διαφορετική διεύθυνση/τηλέφωνο/email.

Στα **Φορολογικά χαρακτηριστικά** καταχωρίζετε τις έξι ενδείξεις και ετικέτες
χωρισμένες με κόμμα, όπως «επιδοτούμενος, ανήλικα τέκνα». Στις **Σημειώσεις**
κρατάτε γενικές παρατηρήσεις. Οι καταγραφές του ημερολογίου και τα tasks
παραμένουν ανεξάρτητα, με τους αρχικούς συντάκτες και ημερομηνίες.

Οι κωδικοί **TaxisNet** είναι διαθέσιμοι σε ιδιοκτήτη και ενεργούς λογιστές
του ίδιου γραφείου. Συμπληρώστε username ΚΑΙ password για αποθήκευση ή
αντικατάσταση. Κενά πεδία διατηρούν ό,τι έχει ήδη αποθηκευτεί. Για αφαίρεση,
επιλέξτε το αντίστοιχο πεδίο χωρίς να εισάγετε νέους κωδικούς. Η εμφάνιση
ανοίγει ξεχωριστή ιδιωτική σελίδα και καταγράφει την πρόσβαση. Αλλαγή ΑΦΜ
με ήδη αποθηκευμένους κωδικούς απαιτεί ρητή αντικατάσταση ή αφαίρεσή τους.
Κρατήστε και τα υφιστάμενα ανεξάρτητα αντίγραφα του εξωτερικού κλειδιού·
οι κωδικοί δεν ανακτώνται μόνο από τη βάση χωρίς αυτό.

Στον κατάλογο συναλλασσομένων τα φίλτρα εφαρμόζονται και στις **PDF/CSV**
εξαγωγές όλων των σελίδων. Μπορείτε να ομαδοποιήσετε ανά ετικέτα, κατηγορία
ή κατάσταση. Σε πολλές ετικέτες η ίδια επαφή εμφανίζεται σε κάθε αντίστοιχη
ομάδα· η σύνοψη μετρά μοναδικές επαφές. Οι εξαγωγές δεν περιλαμβάνουν
κωδικούς, ΑΜΚΑ, στοιχεία συζύγου ή εσωτερικές παρατηρήσεις.

## Εφαρμογή και έλεγχος

Το πακέτο εφαρμόζει μόνο Git/αρχεία στην αρχική CR006, διατηρώντας τις
πραγματικές αναφορές και την υπάρχουσα αποκλειστική δέσμευση. Διορθώνει
την0031 μόνο στα δύο serialize=False και διατηρεί την0032 και όλες τις
αρχικές30 migrations. Οι0033/0034 προσθέτουν το νέο προφίλ και τους ελέγχους.

```bash
python3 tools/verify_cr007.py --record --host-dns
```

Ο χειριστής εκτελεί τη νέα εικόνα/PG17, όλη τη σουίτα και τον πραγματικό
worker/Redis. Ο agent εκτελεί μόνο στατικούς ελέγχους. Το προηγούμενο
CR0061085/36 είναι επιτυχές αποτέλεσμα σουίτας, ενώ ο broker απέτυχε·
δεν παρουσιάζεται ως πλήρες Verified. Η διόρθωση metadata και οι χωριστές
διαγνωστικές φάσεις ελέγχονται ξανά μαζί με τη νέα έκδοση.

Το VM και το GitHub παραμένουν στην CR005, σύμφωνα με τη ρητή αναμονή
του χρήστη, ανεξάρτητα από το αποτέλεσμα του τοπικού ελέγχου. Όλες οι85
πλήρεις αποδοχές και η τελική αποδοχή από λογιστή παραμένουν Pending.
