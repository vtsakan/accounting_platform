# Ενεργοποίηση δοκιμαστικών συνημμένων στην ήδη εγκατεστημένη CR008

Η πραγματική αναφορά στο GitHub `24b3279` καταγράφει επιτυχή εγκατάσταση
CR008, εφαρμογή `b493521`, διάθεση `ab10d6f`, 36 migrations και επαναφορές
53/61 πινάκων. Το VM είναι ήδη στη νέα εφαρμογή, με τις μεταφορτώσεις κλειστές.
Το παλιό `private/vm-cr008-preview.json` είναι η καταγραφή αυτής της ολοκληρωμένης
εργασίας. Διατηρείται μαζί με το παλιό journal και την πραγματική αναφορά.

Η νέα εντολή αλλάζει αποκλειστικά το προφίλ στην ΙΔΙΑ ΤΡΕΧΟΥΣΑ βάση36. Δεν
κάνει clone, migrations, build, image push ή επιλογή της διατηρημένης παλιάς
βάσης30. Η εικόνα παραμένει η ίδια με 1.186/1.186 και 36 οικονομικές περιπτώσεις.
Κρατά χρήστες, MFA, κλειδιά, συνεδρίες, τρέχουσες κινήσεις/εργασίες και ουρά.

## Εκτέλεση

```bash
bash ~/Downloads/accounting-platform-CR008-existing-4GB-profile/UPDATE_GITHUB_AND_VM.sh
```

Το APPLY ελέγχει την πραγματική πηγή, τη γνήσια ιστορία και τις προηγούμενες
αναφορές. Δεσμεύει αποκλειστικά 18 πραγματικά αρχεία, διατηρώντας όλες τις
παλιές δεσμεύσεις. Προσθέτει νέα εργαλεία χωρίς patch στο `state.md`. Η δική
του καταγραφή προστίθεται μόνο μετά την επιτυχία, χωρίς εξάρτηση από αρχικό
Git blob ή αλλαγή των παλιών τμημάτων. Άγνωστες αλλαγές δεν γίνονται αυτόματα
commit, stash ή reset. Δεν ανακατασκευάζεται η γνήσια ιστορία του χειριστή.

Το UPDATE εκτελεί τους 52 υπάρχοντες και 21 επιπλέον ελέγχους εργαλείων,
νέο έλεγχο πηγής/ιστορίας και κανονικό GitHub fast-forward. Χρειάζονται οι
ίδιες συνδέσεις GitHub/gcloud/IAP, τοπικό Docker και το υπάρχον ανεξάρτητο
`~/.config/totalaccounting/recovered-backup-age.key`.

Νέα ξεχωριστή ρύθμιση: `private/vm-cr008-4gb-profile.json`. Νέο journal:
`/etc/accounting/cr008-4gb-profile-state.json`. Η παλιά ολοκληρωμένη ρύθμιση
και το `/etc/accounting/cr008-preview-state.json` δεν αλλάζουν. Το `status`
μπορεί να διαβάσει και την παλιά εγκατάσταση πριν δημιουργηθεί η νέα ρύθμιση.

## Τι αλλάζει στο VM των 4 GB

Χρησιμοποιείται το ήδη προετοιμασμένο ιδιωτικό προφίλ επτά υπηρεσιών: δύο
web workers, πραγματικός ClamD με 2.560 MiB RAM / 4.096 MiB RAM+swap και
2 GiB υπάρχοντος ή αποκλειστικά δεσμευμένου swap στον ίδιο δίσκο. Τα υπόλοιπα
όρια είναι web512, PostgreSQL768, Redis192, worker256, scheduler128, Caddy128 MiB.
Δεν αλλάζει μέγεθος VM ή το PostgreSQL container/process. Ο σαρωτής δεν έχει
δημόσια θύρα, Internet, database ή κλειδιά εφαρμογής. Οι υπογραφές ενημερώνονται
σειριακά, με σταματημένο daemon, καθημερινά στις 04:30 Europe/Athens.

Παραμένουν όλοι οι έλεγχοι antivirus/τύπου/μεγέθους και τα ίδια permissions.
Όριο αρχείου25MiB και HTTP σώματος28MiB. Αποτυχία ή παλιές υπογραφές απορρίπτουν
τη μεταφόρτωση χωρίς αποθήκευση. Το προφίλ είναι για δοκιμή, με μικρά αρχεία·
το swap είναι πιο αργό από RAM και δεν αποτελεί αποδοχή παραγωγικού φόρτου.

## Τρέχουσα βάση και επαναφορές

1. Η εντολή διαβάζει και επιβεβαιώνει την παλιά ολοκληρωμένη εγκατάσταση και
   την ενεργή βάση36 στο πραγματικό VM, με το ίδιο image/ρόλο/κλειδιά.
2. Σταματούν ομαλά scheduler, worker και HTTP εγγραφές και λαμβάνεται νέο
   κρυπτογραφημένο backup όλων των 61 τρεχόντων δημόσιων πινάκων.
3. Η ίδια βάση συνδέεται στο νέο προφίλ. Απαιτούνται ισότητα όλων των αρχικών
   γραμμών και πραγματική σάρωση καθαρού stream, EICAR και fail-closed, καθώς
   και διαθέσιμη μνήμη/swap χωρίς OOM. Δεν δημιουργούνται δοκιμαστικοί πελάτες
   ή επαγγελματικές εγγραφές για τη σάρωση.
4. Λαμβάνεται δεύτερο backup. Και τα δύο επαναφέρονται εκτός VM με το ανεξάρτητο
   κλειδί και ακριβή ταύτιση61/61 πινάκων πριν ανοίξουν οι δημόσιες εγγραφές.
5. Ενεργοποιούνται οι υπηρεσίες και ελέγχονται HTTPS/CSRF, δέκα στατικά αρχεία,
   μνήμη, σαρωτής, worker, singleton scheduler και η ίδια διατηρημένη ουρά.

Αν αποτύχει το προφίλ, η επαναφορά ρύθμισης κρατά την ΙΔΙΑ ΤΡΕΧΟΥΣΑ βάση,
την ίδια εικόνα και κάθε νέα εγγραφή. Απενεργοποιεί τις νέες μεταφορτώσεις και
επαναφέρει την προηγούμενη διάταξη υπηρεσιών. Ποτέ δεν επιστρέφει στη βάση30,
δεν κάνει restore πάνω στην ενεργή βάση και δεν διαγράφει τα νεότερα δεδομένα.

```bash
python3 tools/preview_cr008_profile_release.py status
python3 tools/preview_cr008_profile_release.py resume

```

μόνο στατικούς ελέγχους, όχι τους 73 ελέγχους ή πραγματική αλλαγή VM.
