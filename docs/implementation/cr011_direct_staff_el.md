# Δημιουργία χρηστών χωρίς email

1. Ως υπεύθυνος ανοίγετε **Γραφείο → Χρήστες** και **Νέος χρήστης χωρίς πρόσκληση**.
2. Δίνετε όνομα χρήστη, ρόλο λογιστή ή υπευθύνου και προσωρινό κωδικό δύο φορές.
3. Επιβεβαιώνετε τον δικό σας κωδικό και πρόσφατο MFA. Αποθηκεύετε και παραδίδετε
   τα στοιχεία στον συνεργάτη. Η εφαρμογή δεν τα στέλνει με email.
4. Στην πρώτη σύνδεση ο συνεργάτης αλλάζει υποχρεωτικά τον προσωρινό κωδικό,
   πριν αποκτήσει πρόσβαση. Οι υπεύθυνοι συνεχίζουν με την κανονική επαλήθευση
   συσκευής. Στη λίστα φαίνεται ποιοι περιμένουν αλλαγή κωδικού.

Για επαναφορά επιλέγετε **Επαναφορά κωδικού** δίπλα σε ΑΛΛΟΝ χρήστη του
γραφείου και δίνετε νέο προσωρινό κωδικό. Οι παλιές συνεδρίες λήγουν. Ο ρόλος,
η ενεργοποίηση, οι συσκευές MFA και οι κωδικοί ανάκτησης διατηρούνται.
