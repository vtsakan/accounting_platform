## EX-013 — Η στρογγυλοποίηση ανά γραμμή διαφέρει από τη στρογγυλοποίηση συνόλου

Τρεις παράγωγες γραμμές 0,335 €: προτεινόμενη HALF_UP ανά γραμμή.

| Έλεγχος | Πράξη με ακριβή δεκαδικά | Αναμενόμενο ποσό |
| --- | --- | --- |
| `rounded_line_one` | `HALF_UP(0.335 * 1)` | 0,34 € |
| `rounded_line_two` | `HALF_UP(0.335 * 1)` | 0,34 € |
| `rounded_line_three` | `HALF_UP(0.335 * 1)` | 0,34 € |
| `sum_rounded_lines` | `0.34 + 0.34 + 0.34` | 1,02 € |
| `contrasting_round_total` | `HALF_UP(0.335 * 3)` | 1,01 € |

Πρόταση: 0,34 + 0,34 + 0,34 = 1,02 €. Στρογγυλοποίηση του αθροίσματος δίνει 1,01 €. Ο λογιστής πρέπει να επιλέξει τον κανόνα πριν την υλοποίηση. Δεν αποτελεί φορολογική γνωμάτευση.

**Αποφάσεις προς εξέταση:** D08-06. **Μελλοντικά βήματα:** S18, S22, S27, S28.
