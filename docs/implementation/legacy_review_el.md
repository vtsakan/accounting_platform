# Ανασκόπηση μετάπτωσης S25

Το συνθετικό παράδειγμα δεν αποτελεί έγκριση πραγματικών δεδομένων. Η
ανασκόπηση D05, η πύλη G2 και η έναρξη πραγματικής λειτουργίας εκκρεμούν.
Ονόματα υπευθύνων και πραγματικές ταυτότητες καταγράφονται ιδιωτικά.

| Έλεγχος | Τι χρειάζεται να επιβεβαιωθεί |
|---|---|
| Αντίγραφο πηγής | Εξουσιοδότηση, αμετάβλητο αποτύπωμα, χρόνος λήψης και ξεχωριστό ανακτήσιμο αντίγραφο |
| Γραφεία και χρήστες | Ρητή χαρτογράφηση κάθε εγγραφής και ένας μόνο ενεργός χώρος εργασίας ανά λογιστή |
| Ταμεία | Ημερομηνία έναρξης, αρχικό ποσό και ακριβής εξήγηση των προηγούμενων κινήσεων |
| Συμφωνίες | Ελεγμένοι όροι και ρητές χρεώσεις· η παλιά ένδειξη «ολοκληρωμένη» δεν αρκεί |
| Εισπράξεις και πληρωμές | Κάθε ποσό πηγής, κατεύθυνση, ταμείο και δικαιούχος |
| Αντιστοιχίσεις | Ποια είσπραξη εξοφλεί ποια χρέωση, μέχρι ποιο ποσό και από ποια ημερομηνία |
| Πιστωτικά και προκαταβολές | Χωριστά ανά συναλλασσόμενο και πηγή, χωρίς αυτόματο συμψηφισμό |
| Εσωτερικές μεταφορές | Δύο αντίθετα ίσα σκέλη και ανεξάρτητη τεκμηρίωση· το UUID μόνο του δεν αρκεί |
| Εξαιρέσεις | Αιτία, ενέργεια και αναφορά για κάθε αρχειοθετημένη ή δεσμευμένη εγγραφή |
| Συμφωνία | Μηδενική ανεξήγητη διαφορά ανά ταμείο, χρέωση, κίνηση, αντιστοίχιση και μεταφορά |
| Ανάκτηση | Πραγματική επαναφορά του αρχικού σημείου δοκιμής με διαθέσιμα τα αναγκαία κλειδιά |
| Μετάβαση | Χρόνος παύσης εγγραφών, υπεύθυνος αποδοχής, υπεύθυνος επαναφοράς και κανόνας αποτυχίας |

Οι ιδιωτικές αναφορές είναι `dry-run.csv`, `reconciliation.csv` και
`source-to-target.json`. Μετά τη συνθετική τεχνική δοκιμή εξετάζεται το
πραγματικό αντίγραφο και εγκρίνονται οι σχετικές αποφάσεις. Ο κώδικας δεν
υπογράφει αυτές τις εγκρίσεις για τον λογιστή ή τον ιδιοκτήτη.
