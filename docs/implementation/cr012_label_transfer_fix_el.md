# CR012-LABEL — διόρθωση μεταφοράς τεκμηρίωσης στο VM

Η τελευταία έξοδος του χειριστή καταγράφει249 επιτυχείς ελέγχους και GitHub
main στοf5ccfa463d4afda2ba30109ea13981ea47e0a1ba. Η εντολή του VM σταμάτησε
με γενικό RuntimeError, χωρίς να εμφανιστεί το μήνυμα έναρξης των backup.

Ο έλεγχος του πηγαίου κώδικα εντόπισε ελλιπή μεταφορά: ο έλεγχος του παλιού
ολοκληρωμένου CR012 χρειάζεται το δικό του αρχείο δέσμευσης αναφοράς, αλλά
στο προσωρινό directory μεταφέρονταν μόνο η νέα δέσμευση και η αναφορά LABEL.
Αυτός ο έλεγχος προηγείται της αποθήκευσης plan/journal και της παύσης υπηρεσιών.
Η πραγματική κατάσταση του VM θα επιβεβαιωθεί από τον νέο updater.

Το διορθωμένο πακέτο μεταφέρει από το ίδιο αμετάβλητο Git archive και τα37
δεσμευμένα ιστορικά αρχεία, μαζί με τη δέσμευση αυτού του deployment (38 συνολικά).
Στο VM όλα συγκρίνονται byte προς byte με το archive. Οι προηγούμενες αναφορές
και δεσμεύσεις δεν ξαναγράφονται.

Το APPLY αλλάζει μόνο τα δηλωμένα εργαλεία και έγγραφα του Git. Διατηρεί αυτούσια
τα πραγματικά AGENTS.md/state.md, το αρχικό manifest/preflight σε χωριστά snapshots
και όλες τις πραγματικές αναφορές. Δεν εκτελεί εφαρμογή, δοκιμές ή cloud ενέργειες.

Το UPDATE εκτελεί257 ελέγχους εργαλείων: τους προηγούμενους249 και8 νέους για
τη μεταφορά και την ασφαλή επανάληψη. Για την ακριβή εκκρεμή ρύθμισηf5cc με το
αρχικό manifest επιτρέπεται αλλαγή του deployment commit μόνο όταν το VM
επιβεβαιώσει ότι δεν υπάρχουν LABEL plan, journal ή hold, η παλιά εγκατάσταση
και τα backup παραμένουν δεσμευμένα στην ίδια πηγή, και τα έξι παλιά journals
παραμένουν ακριβή. Ακολουθεί πλήρης διορθωμένος έλεγχος plan πριν αλλάξει η
τοπική εκκρεμής ρύθμιση. Διατηρείται ακριβές ιδιωτικό αντίγραφό της.

Αν κάποιος έλεγχος διαφέρει, η διαδικασία σταματά για έλεγχο κατάστασης. Δεν
διαγράφει journals, δεν κάνει reset/stash και δεν παρακάμπτει προστασίες.

Εκτέλεση στον ίδιο υπολογιστή με το προηγούμενο επιτυχές1393/36 LABEL image:

```bash
bash ~/Downloads/accounting-platform-CR012-label-evidence-transfer-fix/UPDATE_GITHUB_AND_VM.sh
```

Χρειάζονται οι υπάρχουσες συνδέσεις GitHub/gcloud, το τοπικό Docker και το
ανεξάρτητο κλειδί ανάκτησης. Χρησιμοποιείται η ίδια ελεγμένη εικόνα, χωρίς build.
Η κανονική ενεργοποίηση διατηρεί την ίδια βάση42/65 πινάκων, χωρίς clone ή
migration, με τα δύο πραγματικά κρυπτογραφημένα backup/restore εκτός VM.
Λογαριασμοί, MFA, κλειδιά, ουρά και το VM4GB παραμένουν στην υπάρχουσα μορφή.
